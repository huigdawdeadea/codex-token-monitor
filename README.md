# Codex Token Monitor

Windows 本地只读的 Codex Desktop 会话 token 监控器。

它用于回答四个实际问题：当前会话的上下文还有多少余量、每天和每个项目消耗了多少 token、每个 skill 的静态体积及运行归因量是多少、这些消耗最终对应了什么任务结果。程序只在本机读取 Codex Desktop 的 rollout 文件，通过托盘常驻和本地网页展示结果，不上传会话数据。

## 页面功能

| 页面 | 主要用途 |
| --- | --- |
| 当前态势 | 优先查看当前上下文压力、今日处理量和活动会话，再查看最近 7 天、API 等值参考成本、任务标记覆盖率及最近会话。 |
| 用量统计 | 查看今日与累计处理量、每日/每周/每月目录价估算、价格来源覆盖、日期归因分析、最近 14 天趋势和每日明细。 |
| 会话账本 | 搜索、筛选和排序会话，打开只读详情并按用户问题查看 token 与参考成本细分。 |
| 模型对比 | 按模型汇总会话数、累计 token、输入输出构成和 reasoning effort；只描述消耗，不评价模型质量。 |
| 消耗排行 | 按天、会话或项目定位 token 集中的位置，并区分累计量与每日增量。 |
| Skills 归因 | 分开查看 skill 静态体积、高置信度调用、独占 token、协同组合、未归因量和证据详情。 |
| 监控设置 | 管理活动窗口、标题保留、价格检查、开机启动和本地历史清理。 |

## 界面与使用方式

前端采用 Windows 数据控制台布局：暖灰白画布、深墨绿结构色和少量橙色重点提示，七个页面共用任务式中文标题、连续指标带、结构化表格和统一的详情面板。页面不依赖外部字体、图片、CDN 或前端框架。

- 当前态势使用三列优先区，同时展示上下文压力、今日处理量和活动会话。
- 大数字使用适合数值阅读的等宽字体，颜色只用于区分正常、警告、危险和关键成本。
- 表格、模型卡、排行榜、设置表单和会话详情保持同一套信息密度与交互层级。
- 桌面基准宽度为 `1180px`；窄于 `900px` 时侧栏改为横向导航，主要指标、价格与设置卡改为单列。
- 动效只用于页面进入、刷新和状态变化，并遵循系统的“减少动态效果”设置。

### 价格更新与当前 Gate

- 价格按模型、输入/缓存输入/输出字段和生效时间版本化保存；每条 token 事件按发生时间匹配价格区间。
- 后台协调器支持启动检查、每 24 小时检查、手动检查、48 小时过期标记和最后可信版本降级。
- 单项价格变化超过 50% 时先隔离，连续两次取得相同结果后才启用。
- 第一条远程价格之前的事件使用时间上最近的后续价格，并标记为回填估算；已知模型完全没有远程价格时才使用内置默认价。
- 未知模型只在已批准来源中做精确名称查找；不使用模糊名称、模型家族或平均价格猜价。
- OpenAI 官方价格源已接入 `https://developers.openai.com/api/docs/pricing.md`，解析官方 Standard pricing data 表，并只导入实际观测到的模型；每次抓取记录内容哈希、ETag、抓取时间和价格版本。
- LiteLLM 适配器仍默认禁用，只有完成其当前文件、提交、格式和许可证核验后才应启用。

它把两个不同概念分开显示：

- 会话累计处理量：Codex 报告的累计 input、output 和 total token，包含该会话历次调用。
- 当前上下文估算：Codex 最近报告的上下文 token 除以模型上下文窗口。

例如，页面可能同时显示“累计处理量 119.1 万”和“当前上下文 145,403 / 258,400，56%”。两者口径不同，不应相等。Codex 客户端右下角的上下文数字应与页面的“当前上下文估算”比较，而不是与会话卡中的累计处理量比较。累计处理量持续增加；Codex 压缩上下文后，当前上下文估算可能下降。

## 主要能力

- 实时监听当前电脑上的 Codex Desktop rollout JSONL。
- 扫描当前可用及历史 skill 定义，使用本地 `o200k_base` tokenizer 统计 `SKILL.md` 基础体积；无法精确计数时明确标为估算。
- 从成功读取 skill 后的模型调用窗口做运行归因：单 skill 进入独占桶，多 skill 进入稳定协同组合，同一模型调用只计算一次。
- Skills 主排行默认只纳入完整 `SKILL.md` 读取形成的高置信度调用；普通文本提及不会被当作调用。
- 按会话展示累计处理量、当前上下文估算、输入输出细分、模型、reasoning effort、活动时间和采集状态。
- 会话账本支持点击“累计 token”表头，在从高到低与从低到高之间切换；搜索、筛选和自动刷新会保留当前排序。
- 按 Windows 本地日期汇总今日处理量、累计处理量、最近 14 天趋势和最近 7 天明细。
- 展示每日、每周和每月按历史价格区间折算的美元目录价估算，并单独展示官方、第三方、内置默认和未计价覆盖。
- 会话卡片和会话账本展示每个会话的 API 等值参考成本；会话详情展示该会话所用模型、总参考成本及 token 计价细分。
- 会话详情可按用户问题查看模型、模型调用次数、输入、缓存输入、输出、总 token 和参考成本，最多展示最近 200 个问题。
- 每日统计累加每次 token 事件的 `last_token_usage`，重复扫描不会重复计数。
- 可选择最近 14 天中的任意日期，查看相对前一天、此前 7 个自然日日均值的变化，以及当日 Top 5 会话贡献。
- 可在任意会话详情中手动标记任务类型、最终结果、人工耗时和返工原因。
- 分析页展示已标记覆盖率、已完成任务平均 token 和返工 token 占比，把消耗与结果关联起来。
- 消耗排行提供按天、按会话和按项目三种口径；项目榜可在所选日期明细与历史累计之间切换。日期明细按逻辑 Git 项目归并工作树，可展开查看每个会话当天的 token 分类；累计榜继续显示会话数、模型数、累计 token、API 等值参考成本及未计价 token。
- 每个会话的当前结果标记会应用到它出现过的历史日期。它不是当时状态的历史快照。
- 分析结果提供消耗与结果数据，不把 token 多少单独判断为任务效率或质量。
- 可从概览页的其他会话卡片或会话账本打开任意会话的只读详情面板。
- 托盘常驻，双击打开仅绑定 `127.0.0.1` 的本地网页。
- 程序已在后台运行时，再次双击 EXE 会通知已有实例打开当前监控页面，不会静默退出。
- 提供会话历史、模型汇总、标题保留和数据清理。
- 只展示 token 和上下文状态，不发送超量提醒。
- 发布版可选择随 Windows 登录启动，默认关闭。

## 隐私边界

监控器持续采集时只从 Codex 文件中提取白名单元数据：会话 ID、标题、模型、reasoning effort、项目工作目录、时间和 token 数字。项目工作目录优先归并到已有 Git 仓库根目录，用于项目消耗统计。只有在用户打开某个会话详情时，监控器才会从该会话的原始 rollout 文件只读提取用户问题预览，用于逐问题明细；问题正文不写入监控器数据库。

- Codex 源文件只读打开，不修改、不删除。
- Skill 文件同样只读；数据库仅保存路径、内容哈希、计数、证据和归因结果，不保存 skill 正文或完整工具输出。
- 监控器数据库位于 `%LOCALAPPDATA%\CodexTokenMonitor\monitor.db`。
- 标题是唯一保存的正文衍生字段，默认保留 90 天，可关闭采集或一键清除。
- 任务结果标记由用户手动填写，只写入监控器自己的 `session_annotations` 表，不修改 Codex 文件。
- 任务结果使用固定选项和可选分钟数，不保存自由文本备注。
- 逐问题预览最多截取 280 个字符，只在详情请求期间读取；不读取助手回复、工具输出、命令内容或工作区文件内容。
- 本地网页不监听局域网地址，不使用外部 CDN，不上传数据。
- 价格来源启用后只读取白名单中的公开价格文件；最多使用公开模型标识做精确匹配，不发送 token 数量、会话标题、时间记录或设备信息。
- `?mask=1` 可在共享屏幕或截图时隐藏标题、项目名称与路径、问题正文，并缩短会话 ID。

## 数据来源与兼容性

实时主来源：

```text
%USERPROFILE%\.codex\sessions\YYYY\MM\DD\rollout-*.jsonl
```

模型、reasoning effort 和可选标题从 Codex 本地索引与只读 SQLite 补充。这些都是 Codex 当前版本的本地实现细节，不是公开稳定 API。监控器遇到无法识别的格式时保留最后成功值，并在页面显示停止更新或降级状态，不会用 0 冒充真实数据。

## 开发

需要 .NET 8 SDK：

```powershell
dotnet restore CodexTokenMonitor.sln
dotnet test tests\CodexTokenMonitor.Tests\CodexTokenMonitor.Tests.csproj --no-restore
dotnet build CodexTokenMonitor.sln --no-restore
```

运行开发版：

```powershell
dotnet run --project src\CodexTokenMonitor.App\CodexTokenMonitor.App.csproj -- --no-browser
```

开发版不会启用 Windows 登录启动开关。

测试或并行验证时可设置 `CODEX_TOKEN_MONITOR_DATA_HOME` 使用独立数据目录，并传入 `--validation-instance=<suffix>` 避免复用正式实例的互斥锁和激活事件。

## 发布

创建 Windows x64 自包含发布目录：

```powershell
.\scripts\Publish.ps1
```

输出位于 `publish\win-x64`。运行 `CodexTokenMonitor.App.exe` 后，程序进入托盘并打开监控页面。关闭浏览器标签不会退出监控器，需要从托盘菜单选择“退出”。

## 当前边界

第一版不监控 Codex CLI、ChatGPT 网页版、OpenAI API 或其他电脑；不读取实际订阅或 API 账单，不提供远程会话同步、安装器和应用程序自动更新；不会自动停止、压缩或切换 Codex 会话。页面中的费用是按可追溯价格等级计算的目录价估算，不是账户实际账单。Skill 运行归因表示其生效窗口内的处理量，不代表移除该 skill 后可节省的反事实成本。完全未知且无法精确匹配价格的模型显示“无法计价”，不会按 0 美元处理。
